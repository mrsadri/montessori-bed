# Montessori floor bed 70x130 (v2)

Interactive 3D model (`index.html`) and build guide PDF (`montessori-bed-guide-v2.pdf`).

## Publish on GitHub Pages
1. Create a new public repository and upload both files to its root (keep the PDF name unchanged).
2. Settings > Pages > Build and deployment > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, Save.
3. After a minute the page is live at `https://<username>.github.io/<repo>/`.
